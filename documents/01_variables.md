## Variables


A variable is a container and you can put a value in it. 
for example,
    
```python
num = 90
```
here, num is a variable and its value is 90. 


A variable's value can be changed.
for example,

```python
score = 90
score = 100
```

Here, score is 90 and then 100 in the next line.

In python words are called strings,

```python
name = "Gunjan"
```

So "Gunjan" is a string. but string can also be a sentence.
for example,

```python
sen = "Gunjan is awesome"
```
"Gunjan is awesome" is a string. Also, there is a rule in python regarding the strings just like most of the other programming languages which is that strings must also be inside a set of double quotes or single quotes.

```python
name = "Priya"
name = 'Priya'
```

The type of value or data a variable contains is called its datatype. 

for example,

```python
name = "Gunjan"
age = 1000
weight = 60.4
hungry = False
```

Datatype of name variable here is string, datatype of age variable is integer and datatype of weight is float(all the decimal numbers are called float in coding).
The fourth variable hungry has a datatype called boolean(boolean is a datatype which either True or False)

In python, we have a type() function which can be used to check the datatype of any variable.

for example, type(age), will give us int telling us that variable age's datatype is int. 

## Rules for naming variables.

1. We can't use keywords as variable names.
2. Can't have any special characters other than the underscore(_).
3. Can't start with a number. the number can come later in the variable just not in the first place.
4. white spaces aren't allowed.
5. python is a case-sensitive language, which means a variable name Key is different from key because in python "K" and "k" are not same.
